# Xiaoli98 v3 (bản miễn phí)
App nhắn tin kiểu WeChat: đăng ký/đăng nhập, tìm bạn, lời mời kết bạn, chặn, báo cáo, chat 1-1 và nhóm, gửi ảnh, Khoảnh khắc,
gọi thoại + video (WebRTC), thông báo đẩy (Web Push), Việt/Anh/Trung, xóa tài khoản, lưu trữ MongoDB Atlas.

Bắt đầu: đọc **docs/HUONG-DAN.md**.
    npm install && npm test && npm start     (http://localhost:3000)
